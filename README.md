# My-Projects

Data Analytics Dashboard & Automation Project
A comprehensive Excel-based data analysis project utilizing Power Pivot, VBA Automation, and Dynamic Visualization to transform raw data into actionable insights. This project demonstrates advanced spreadsheet engineering, including complex data modeling and interactive UI elements.

📁 Project Structure
The underlying architecture of this .xlsm file consists of several integrated components:


Data Modeling: Multiple Pivot Tables (pivotTable1 through pivotTable4) connected via a centralized pivotCache for efficient data processing.


Visual Analytics: A suite of custom-styled charts (chart1, chart2, chart3) featuring bespoke color themes and styles.


Interactivity: Integrated Slicers and Timeline Controls (slicer1, ctrlProp1-4) for dynamic data filtering.
+2


Automation: A vbaProject.bin module containing custom macros to automate repetitive tasks and enhance user workflow.

🚀 Key Features

Multi-Pivot Architecture: Leverages four distinct Pivot Tables to cross-reference data points and provide multi-dimensional analysis.


Dynamic Visualizations: Utilizes customized drawing layers and chart styles to provide a professional, dashboard-style interface.


VBA Enhanced: Includes Macro support to streamline data updates or UI interactions.


Centralized Style & Theme: Uses custom XML-defined themes and shared string tables to ensure consistency across all worksheets and visualizations.

📖 How to Use
Enable Macros: Upon opening the .xlsm file, ensure you "Enable Content" to allow the VBA scripts to function.

Interact with Slicers: Use the visual slicers on the dashboard to filter all connected charts and tables simultaneously.

Data Updates: Update the source data in the primary sheets and refresh the Pivot Tables to see real-time updates in the visualizations.
